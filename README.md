# UXR Expert Interview Case

一个面向资深 / 专家级用户研究员（UXR）的面试项目梳理 Skill。

它不是把研究报告简单压缩成 STAR，而是帮助求职者从真实项目材料出发，逐步完成：事实还原、能力证明目标（Case Proof Goal）、研究决策链、核心洞察、业务转译、归因边界、面试母稿、5 分钟 / 3 分钟版本以及追问模拟。

## 适合谁

适合有复杂项目经验的 Senior UXR、用户研究专家、研究 Lead、研究 BP，以及正在准备专家级用户研究岗位面试的候选人。

## 怎么使用

将仓库中的 `SKILL.md` 提供给支持 Skill / Agent 工作流的 AI 助手，然后直接从一个真实项目开始。推荐的第一句话：

> 我是一名有 X 年经验的用户研究员，正在准备 XX 岗位的面试。我想用这个 Skill 梳理一个代表项目。这是我当年的项目报告 / PPT / 复盘 / 简历材料。请先帮我还原项目，不要直接写 STAR 或面试稿。如果材料里有不确定的信息，请问我，不要自行补全。

如果没有完整材料，也可以让助手一次只问一个模块，通过访谈式方式还原项目。

## 核心原则

> 面试项目不是研究报告的缩写版，而是一条能力证明链。

Skill 强调：先理解再表达；区分已有认知与新增发现；解释为什么这样设计研究；把大量 Findings 提炼为少数 Core Judgments；建立 Insight → Business Question → Owner → Action → Evidence 的业务转译链；并严格控制 UXR 与 PM / DA / Algorithm / Product 后续成果之间的归因边界。

## 文件

- `SKILL.md`：完整 Skill，包括 Quick Start、Agent Interaction Protocol、Stage Gates、项目分析工作流、Interview Mode、Case Worksheet、Checklist 和脱敏示例。

## 推荐工作流

提供真实材料 → 还原项目事实 → 确认 Case Proof Goal → 重建研究决策链 → 提炼 Core Judgments → 审计业务落地与归因 → 生成面试母稿 → 压缩为 5 分钟 / 3 分钟 → 模拟面试与连续追问。

## 与 uxr-expert-resume 的关系

`uxr-expert-resume` 解决“哪些经历值得写进专家级 UXR 简历，以及如何证明价值”；本 Skill 进一步解决“选定一个代表项目以后，如何把它展开成经得起面试追问的专家级案例”。
